# Yol Haritası

## ✅ Aşama 1 — Proje Kurulumu ve Marka Tasarımı
Next.js kurulumu, marka renk paleti, tipografi, ana sayfa (hero, kategori
bölümleri, ürün rayları, footer). Responsive tasarım.

## ✅ Aşama 2 — Ürün Arayüzleri
Kategori listeleme sayfası (beden/renk/fiyat/kalıp/stok filtreleri,
sıralama), ürün detay sayfası (galeri, varyant seçimi, beden rehberi,
kombin önerileri, benzer ürünler).

## ✅ Aşama 3 — Backend
ASP.NET Core 10 Web API, katmanlı mimari, PostgreSQL + EF Core, ürün ve
kategori endpoint'leri. Frontend artık demo veri yerine gerçek backend'den
veri çekiyor. Kombin önerileri ve beden tabloları backend'de modellendi.
